Markdown 的好处是，用很少的标记就能表达清晰的结构。内容始终是纯文本，迁移和维护也更简单。

<!-- more -->

## 先组织结构

用 `##` 表示二级标题，用 `###` 表示三级标题。文章标题已由主题生成，正文通常从二级标题开始。

**加粗**用于强调关键概念，*斜体*可以表达补充语气，`行内代码`适合文件名和短命令。

## 引用与列表

> 写作是把模糊的想法，变成清晰的语言。

一个简单的写作过程：

1. 写出要回答的问题。
2. 用小标题搭出框架。
3. 加入例子，再删掉多余的话。

## 代码与表格

代码块注明语言后，主题会自动高亮，并提供复制按钮：

```javascript
const thoughts = ['观察', '思考', '记录'];
for (const thought of thoughts) {
  console.log(`今天也要认真${thought}。`);
}
```

| 元素 | 写法 | 用途 |
| --- | --- | --- |
| 二级标题 | `## 标题` | 组织章节 |
| 引用 | `> 内容` | 引用或突出观点 |
| 链接 | `[文字](地址)` | 连接相关资料 |

## 图片与摘要

图片放在 `source/img/`，正文使用 `![图片说明](/img/forest.jpg)` 引用。为图片添加具体说明，可以帮助读者理解内容。

文章摘要可以填写在 Front Matter 的 `description` 中。也可以用 `<!-- more -->` 分隔摘要和正文。
